Co muszę umieć na egzamin INF03

1. Projektowanie i tworzenie stron internetowych(HTML & CSS)

  • Semantyka i struktura HTML5:
    • Znajomość elementów sekcjonujących <header>, <nav>, <main>, <section>, <article>, <aside>, <footer>,
    • Tworzenie i formatowanie tekstu nagłówki( <h1> - <h6> ), akapity( <p> ), pogrubienia( <strong> ), kursywy( <em> ), cytaty( <blockquote> ),
    • Tworzenie list numerowanych( <ol> ), wypunktowanych( <ul> ), oraz definicji( <dl> ),
    • Tabele: <table>, <tr>, <td>, <th>, łączenie komórek( <colspan>, <rowspan> ),
    • Formularze i ich kontrolki: <form>, <input> (typy: <text>, <password>, <number>, <raio>, <checkbox>, <date>, <color>, <range>, <submit>, <reset> ), <select>, <option>, <textarea>, <label>, <button>,
    • Multimedia i linki: odnośniki( <a> ), obrazy( <img> ), wideo( <video> ), dźwięk( <audio> ).
  • Stylizowanie za pomocą CSS3
    • Sposoby dołączania stylów: zewnętrzne pliki .css, style wewnęrzne <style>, style wpisane inline( style="" ),
    • Selektory znaczników, klas( . ), indetyfikatorów( # ), atrybutów, potomków, dzieci,
    • Pseudoklasy i pseudoelementy: :hover, :active, :focus, :nth-child, :first-child, :last-child, ::before, ::after,
    • Zmienne CSS ( :root ) oraz funkcja var() ,
    • Model pudełkowy (Box model): margin, padding, border, width, height oraz kasowanie bazowych marginesów: box-sizeing, border-box.
  • Układ strony i pozucjonowanie
    • Domyślne typy wyświetlania: display ( block, inline, inline-block, none ),
    • Pozycjonowanie position ( static, relative, absolute, fixed, sticky ),
    • Opływanie i czyszczenie: float (opływanie elementów) oraz clear (kasowanie elementów),
    • Flexbox: display: flex, kierunki i wyświetlanie ( flex-direction, justify-content, align-items, flex-wrap ), elastyczność elementów ( flex-grow, flex-shrink, flex-basis ),
    • CSS Grid: dislay: grid, tworzenie siatki ( grid-template-colums, grid-template-rows, grid-template-ateas ), jednostka fr, funkcja repeat(), elastyczne układy ( auto-fit, auto-fill, minmax() ) oraz gap,
    • Nowoczesne funkcje wartości płynne skalowanie tekstu i wymiarów za pomocą clamp(MIN, VAL, MAX) oraz funkcje min() i max().
    • Przekształcenia i animacje: transformacje 2D ( transform: translate(), rotate(), scale(), skew() ), płynne przejścia transition() oraz kluczowe klatki animacji ( @keyframes, animation ).
    • RWD (Media Queries): @media screen and (max-width: ...) do dostowowywanie strony do urządzeń mobilnych.
  • obróbka grafiki na potrzeby stron (GIMP/Photoshop):
    • Kadrowanie, zmiana rozdzielczości i rozmiaru obrazu,
    • Eksport do odpowiednich formatów ( .jpg, .png, .gif, .webp ) z uwzględnieniem kompresji i przezroczystości (kanał alpha).
    • prosty montaż, praca na warstwach, nakładanie filtrów, zmiana jasności/kontrastu i koloru,
    • animacje.
